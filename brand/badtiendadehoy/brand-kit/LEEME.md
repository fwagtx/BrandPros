# BAD · Tienda de hoy: brand kit

| Platform | File | Where to upload it |
|---|---|---|
| TikTok | `tiktok/perfil-tiktok-1080x1080.png` | Profile → Edit profile → Change photo |
| Instagram (Threads uses the same one) | `instagram-threads/perfil-instagram-threads-1080x1080.png` | Edit profile → Edit picture |
| YouTube: icon | `youtube/icono-youtube-800x800.png` | YouTube Studio → Customization → Branding → Picture |
| YouTube: banner | `youtube/banner-youtube-2560x1440.png` | YouTube Studio → Customization → Branding → Banner image |
| YouTube: watermark | `youtube/marca-de-agua-youtube-150x150.png` | YouTube Studio → Customization → Branding → Video watermark |
| Facebook: profile | `facebook/perfil-facebook-720x720.png` | Page → Profile picture |
| Facebook: cover | `facebook/portada-facebook-1640x624.png` | Page → Edit cover photo |

- Every profile picture is designed to work as a circle.
- The banner text sits inside the area YouTube shows on phones (1546×423) and inside the middle of the Facebook cover, which is what phones show.
- The source designs are in `../logos/brand.html` if you want to change the text or colors.
